# Mi Vivero — Publicación y administración

## Publicar en Netlify

1. Sube esta carpeta a un repositorio nuevo de GitHub.
2. En Netlify, selecciona **Add new site → Import an existing project** y conecta ese repositorio.
3. Deja el directorio de publicación como `.` y publica el sitio.
4. En Netlify abre **Integrations → Identity** y activa Identity.
5. En Identity, activa **Git Gateway**. Esto permite que el panel guarde cambios en el repositorio y publique automáticamente.
6. Invita el correo de la persona que editará el sitio desde la pestaña **Identity**.

## Editar el sitio

En el sitio ya publicado, entra a `https://tu-dominio.com/admin/` e inicia sesión con la invitación recibida. Allí se puede editar:

- Nombre, eslogan y logo.
- Imagen y textos de portada.
- Textos de la sección Nosotros.
- WhatsApp, correo, dirección y horarios.
- Productos destacados: agregar, editar y eliminar.

Cada vez que pulses **Publish**, Netlify vuelve a publicar el sitio con los cambios.
